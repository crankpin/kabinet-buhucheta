Политика конфиденциальности

Мы не собираем, не храним и не передаём персональные данные пользователей через данный API.

Все запросы обрабатываются только для анализа содержимого публичных файлов сайта (HTML, CSS, JS, JSON).

API используется исключительно для целей аудита клиентского кода.

Если у вас есть вопросы, вы можете связаться с администратором сайта.
