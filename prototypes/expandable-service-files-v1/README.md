# Expandable Service Files v1

Лабораторный прототип блока трёх услуг для главной «Кабинет Бухучёта».

## Цель

Показать три направления как спокойную редакционную композицию: посетитель читает короткое представление, нажимает «Распаковать услугу» и получает достаточно деталей для первичного решения — без ухода с секции и без трёх одинаковых тарифных карточек.

## Сценарий

1. Все три направления закрыты.
2. Клик по «Распаковать услугу» (или по свободной зоне закрытой поверхности) раскрывает одно направление.
3. На desktop соседи сжимаются в боковые стеклянные рейки (номер + короткое имя + «Распаковать»).
4. «Короче!» или `Escape` (фокус внутри блока) возвращает исходную композицию.
5. Основная CTA — «Обсудить мою ситуацию»; вторичная ссылка ведёт на полную страницу услуги.

## Метафора (pass 5)

Стеклянные плакетки + жест «коробка iPhone»:

- **все закрыты** — ровная сетка из трёх плакеток с небольшим зазором (воздух для теней и hover-плавания);
- **одна открыта** — главная плакетка с содержимым; соседи → узкие стеклянные рейки **на своих местах** (без `order`-прыжка);
- материал: `rgba(255,255,255,~0.28–0.44)` + `backdrop-filter: blur(~24px)` + светлая обводка;
- motion: «тугая коробка» — ease `cubic-bezier(0.23, 0.07, 0.16, 1)`, геометрия ~1380 ms, текст в хвосте ~520 ms;
- тексты: «Распаковать услугу» / «Короче!» / CTA «Обсудить мою ситуацию»;
- open-control: **perforated pill** (dotted oval) + отрывной кончик справа (без отдельной линии слева);
- close-control: тихая кнопка «Короче!» + × в правом верхнем углу открытой face, появляется после изнанки (~440 ms);
- veil: **face** на расширяющейся рейке → face (на всю геометрию); изнанка уходит opacity-fade без face-frost на тайтле;
- close: `is-open` держится до конца выравнивания колонок (цена/seal не всплывают); switch ждёт геометрию (~1240 ms) перед изнанкой.

## Desktop (>900px)

- Закрыто: `1fr 1fr 1fr` + gap ~14px; hover — лёгкий подъём (`translateY(-4px)`).
- Открыто: колонки `1fr / rail / rail` | `rail / 1fr / rail` | `rail / rail / 1fr` по выбранной услуге.
- Открытие: сначала ширина (~980 ms), затем высота + текст; закрытие ждёт оседание высоты (~1080 ms) перед возвратом трёх колонок.

## Mobile (≤900px)

- Вертикальный single-open accordion.
- То же стекло; без боковых реек.
- Раскрытие/сворачивание на том же спокойном pacing (~1120 ms / текст с delay ~220 ms).
- Одна колонка внутри раскрытия; touch-target ≥44px.

## Отличие от Tympanus Card Expansion

Берём только идею «выбранная поверхность становится главным содержанием».  
Не копируем: fullscreen, overlay, затемнение страницы, SVG-маску, fixed поверх viewport, блокировку скролла, крестик модалки.

Раскрытие строго внутри секции услуг.
