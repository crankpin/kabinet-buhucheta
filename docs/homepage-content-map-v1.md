# Карта содержания главной v1

Подготовительный документ. Тексты страниц и разметка `site/` на этом этапе не меняются.

Главная — ни старая SEO-простыня, ни пустой распределительный щит.  
Короткие смысловые блоки объясняют, **зачем** дальше идти в услуги, налоги, отзывы и интерактивы.

Приоритет структуры: `/docs` (`sitemap.md`, `page-types.md`, `service-matrix.md`).  
Визуальные поверхности: `visual-principles.md` + `visual-heritage.md`.

---

## 1. Чего на главной быть не должно

- полного пересказа внутренних страниц;
- каталога всех интерактивов отдельным «зоопарком»;
- одинаковых белых карточек в каждой секции;
- запугивающих формулировок про «вашего бухгалтера»;
- выдуманных услуг, цифр, кейсов и гарантий.

---

## 2. Порядок блоков (предварительный)

Порядок можно уточнять после прототипа; смысл блоков зафиксирован.

1. Первый экран  
2. «КТО ВЫ?» (необязательная развилка)  
3. Три услуги с прямыми ссылками  
4. Кому помогает Карина  
5. Что входит в сопровождение  
6. Этичная самопроверка состояния учёта  
7. Кратко о Карине  
8. Налоги и режимы  
9. Налоговый квиз  
10. Этапы начала работы  
11. Отзывы-орбы  
12. География и дистанционная работа  
13. Финальный CTA  
14. Подвал (общий)

Интерактивы не висят сами по себе:

- самопроверка — рядом с объяснением нормального сопровождения;
- налоговый квиз — рядом с темой режимов / выбора формата;
- «КТО ВЫ?» — отдельная необязательная развилка, не замена обзора услуг.

## 3. Блоки подробно

### 3.1. Первый экран

| | |
|--|--|
| **Задача** | Сразу понять: кто Карина, для кого сайт, какой главный шаг |
| **Объём** | Заголовок + 1–2 коротких предложения + CTA-группа; без простыни |
| **Главное действие** | «Получить консультацию» / мессенджер |
| **Ссылки** | `/kontakty/`, мессенджеры; при необходимости якорный скролл к услугам |
| **Поверхность** | Резкий монтаж: типографика + портрет; живой фон сзади; не карточка |
| **Интерактив** | нет (кроме CTA) |
| **Mobile** | Портрет не дробит смысл; один главный CTA; телефоны доступны |

### 3.2. «КТО ВЫ?»

| | |
|--|--|
| **Задача** | Быстро направить ИП / ООО / несколько организаций |
| **Объём** | Три выбора + короткий диалог для третьей ветки |
| **Главное действие** | Переход на услугу или диалог сопровождения |
| **Ссылки** | `/uslugi/buhgalterskoe-soprovozhdenie-ip/`, `/uslugi/buhgalterskoe-soprovozhdenie-ooo-usn/`, Telegram/контакты |
| **Поверхность** | Акцентная плашка/тройка выборов; не сетка «услуг» |
| **Интерактив** | да |
| **Mobile** | Крупные зоны нажатия; закрытие на любом шаге; Escape |

### 3.3. Три услуги

| | |
|--|--|
| **Задача** | Показать коммерческое ядро сайта прямыми ссылками |
| **Объём** | 3 коротких тизера (заголовок + 1–2 предложения) |
| **Главное действие** | Переход на страницу услуги |
| **Ссылки** | `/uslugi/…-ip/`, `/uslugi/…-ooo-usn/`, `/uslugi/nalogovoe-konsultirovanie/`, обзор `/uslugi/` |
| **Поверхность** | Различимые маршруты (номера, полосы, асимметрия) — не три одинаковые white cards |
| **Интерактив** | нет |
| **Mobile** | Вертикальный стек; вся плитка кликабельна |

«КТО ВЫ?» этот блок **не** заменяет.

### 3.4. Кому помогает Карина

| | |
|--|--|
| **Задача** | Узнать себя в отрасли / типе бизнеса |
| **Объём** | Короткий ввод + 4–6 направлений-ссылок (по `sitemap.md`) |
| **Главное действие** | Переход в `/komu-pomogaem/` или отраслевую страницу |
| **Ссылки** | `/komu-pomogaem/` и существующие отраслевые URL |
| **Поверхность** | Список/монтаж ссылок; без иконочного зоопарка |
| **Интерактив** | нет |
| **Mobile** | Читаемый список, без мелкой сетки 6×N |

### 3.5. Что входит в сопровождение

| | |
|--|--|
| **Задача** | Снять страх «а что я вообще покупаю»; контекст перед самопроверкой |
| **Объём** | 5–8 пунктов или 2 колонки «делаем / не делаем» без выдумок |
| **Главное действие** | К услугам или консультации |
| **Ссылки** | `/uslugi/`, страницы ИП/ООО |
| **Поверхность** | Спокойный информационный блок (ПАУЗА после БАХа) |
| **Интерактив** | нет (подготовка к самопроверке) |
| **Mobile** | Короткие строки; без широких таблиц |

### 3.6. Этичная самопроверка состояния учёта

| | |
|--|--|
| **Задача** | Вовлечь через проверку **процессов и состояния учёта**, не личности бухгалтера |
| **Объём** | Короткий лид + чек-лист; итог → CTA к услугам / Telegram |
| **Главное действие** | Пройти чек-лист → `/uslugi/` или консультация |
| **Ссылки** | `/uslugi/`; при необходимости `/poleznoe/…` (URL можно сохранить, подпись — этичная) |
| **Поверхность** | Встроенный интерактив на странице (не уводить «в никуда») |
| **Интерактив** | да |
| **Mobile** | Крупные чекбоксы; итог с `aria-live`; без hover-only подсказок |

#### Запрещённые формулировки

- «У вас есть бухгалтер? Проверьте его.»
- «Убедитесь, что бухгалтер вас не подводит.»
- любые формулировки, которые без оснований бьют по доверию к действующему специалисту.

#### Рабочие варианты названия (окончательно не выбирать)

1. «Учёт под контролем?»  
2. «Самопроверка учёта»  
3. «Проверить состояние учёта»  
4. «Порядок в учёте»  
5. «Диагностика учётных процессов»

### 3.7. Кратко о Карине

| | |
|--|--|

| **Главное действие** | `/o-karine/` |
| **Ссылки** | `/o-karine/`, при необходимости `/kontakty/` |

| **Интерактив** | нет |
| **Mobile** | Фото не выше смысла; кнопка «О Карине» |

Это не дублирование полной страницы: главная знакомит, `/o-karine/` доказывает путь, квалификацию, принципы и границы работы.

### 3.9. Налоговый квиз

| | |
|--|--|
| **Задача** | Помочь сориентироваться в режиме/ситуации и привести к консультации/услуге |
| **Объём** | Короткий квиз; итог честный, без выдуманных гарантий |
| **Главное действие** | CTA к услугам / Telegram |
| **Ссылки** | `/uslugi/`, `/nalogi/…`, контакты |
| **Поверхность** | Встроенный интерактив рядом с налоговым контекстом |
| **Интерактив** | да |
| **Mobile** | Один вопрос на экран или компактный стек; `aria-live` для итога |

Логику подсчёта (какие ответы влияют на итог) при реализации сверять с продуктовой матрицей — не оставлять «итог только по 2 вопросам» без явного смысла.

## 5. Сезонность на главной

- Контактный объект в углу: ромашка / мандаринка по сезону (`visual-heritage.md` §5).
- Снег не является блоком содержания главной; не занимает место в порядке секций.
- Сезонный код не должен влиять на LCP первого экрана вне сезона.

## 8. Граница этапа

Этот документ **не** разрешает:

- менять CSS/JS/PHP публичного сайта;
- переносить орбы «на глаз»;
- писать финальные маркетинговые тексты;
- придумывать услуги и цифры.

Следующий этап (отдельное задание): визуальная система на главной и странице сопровождения ИП — **после приёмки** `visual-heritage.md`, `navigation-model-v1.md` и этого файла.
