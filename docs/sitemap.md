# Карта сайта «Кабинет Бухучёта» v2

## 1. Задача архитектуры

Новая версия сайта должна стать многостраничным экспертным сайтом, а не одним длинным лендингом.

Основные коммерческие направления:

1. Бухгалтерское сопровождение ИП.
2. Бухгалтерское сопровождение ООО на УСН.
3. Налоговое консультирование.

Страницы сопровождения ИП и ООО не объединяются в одну SEO-страницу: у этих аудиторий разные запросы, задачи, страхи и критерии выбора.

## 2. Верхняя навигация

- Услуги
- Налоги и режимы
- Кому помогаем
- Полезное
- О Карине
- Контакты

Постоянная CTA-кнопка:

**Получить консультацию**

Раздел «География» не выносится в верхнее меню, чтобы не перегружать шапку. Региональные страницы доступны из блока на главной, со страниц услуг и из подвала.

Раздел «Практика» технически предусматривается, но до появления реальных материалов не показывается в меню.

## 3. Интерактив на главной

### КТО ВЫ?

- **Я — ИП** → `/uslugi/buhgalterskoe-soprovozhdenie-ip/`
- **У меня ООО** → `/uslugi/buhgalterskoe-soprovozhdenie-ooo-usn/`
- **У меня несколько разных организаций** → открывает короткий интерактивный сценарий

Сценарий третьей ветки:

1. Какая у вас структура?
   - ИП и ООО
   - несколько ООО
   - несколько ИП/направлений
   - другая структура
2. Какие налоговые режимы используются?
3. Сколько организаций требуется сопровождать?
4. CTA: «Обсудить единый порядок сопровождения»

Отдельная SEO-страница под этот сценарий на первом этапе не требуется.

- включается после появления реальных историй или практических разборов.

## 5. Логика перелинковки

Каждая коммерческая страница должна вести:

- к подходящей услуге;
- к соответствующему налоговому режиму;
- к релевантной отрасли;
- к приоритетному региону;
- к консультации.

Примеры:

- «ООО на УСН» → оптовая торговля → Москва → консультация.
- «ИП на УСН с НДС» → розничная торговля → Ростовская область → сопровождение ИП.
- «Переход с ПСН» → налоговое консультирование → сопровождение ИП.

## 6. Что не делать

- Не создавать общую основную посадочную «Бухгалтерское сопровождение ИП и ООО».
- Не дублировать страницы с заменой только региона или отрасли.
- Не выводить пустой раздел «Практика».
- Не создавать отдельные страницы для работ, которые не продаются отдельно.
- Не таргетироваться по всей России на первом этапе.
