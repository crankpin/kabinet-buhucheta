# Визуальное наследие старого сайта

Документ этапа инвентаризации перед визуальным переоформлением.  
**Не является заданием на редизайн.** Публичный код в `site/` по этому документу не меняется.

Источники:

- `legacy/public_html/` — только чтение, фирменная пластика и поведение;
- `/docs` — приоритет при конфликте бизнес-структуры и URL;
- текущий `site/` — каркас многостраничного сайта, упрощённый визуал.

---

## 1. Философия наследования

Старый одностраничный сайт — не «неудачный черновик», а носитель выстраданного характера бренда.

Новый сайт:

- **наследует характер**, а не копирует сырую реализацию;
- работает по формуле из `visual-principles.md`: **70% спокойной редакционной ясности / 30% выразительных акцентов**;
- сохраняет живой, личный, слегка игровой тон;
- **не** становится советским агитплакатом, красно-чёрной пародией или сеткой одинаковых белых карточек.

Рабочий принцип переноса:

> Сохранить механику и узнаваемость → успокоить движение → усилить ясность → отдельно спроектировать мобильный опыт.

## 3. Детальный аудит

### 3.1. Многослойный фон

| | |
|--|--|
| **Legacy-файлы** | `legacy/public_html/css/main.min.css`; оболочка `body` / `.wrapper` в `index.html` |
| **Селекторы** | `:root` (`--sky-light`, `--sky-medium`, `--sky-deep`, `--sun-glow`, `--gold-accent`); `body`; `body::before`; `body::after`; `@keyframes skyFlow`, `cloudMove`, `textureMove`, `shinePulse` |
| **JS** | нет |
| **Ассеты** | inline SVG `feTurbulence` как data-URL в `body::before` |
| **В покое** | непрерывный сдвиг неба, дрейф шума, пульс золотого свечения |
| **Hover / focus / click / scroll** | фон сам на события не реагирует (реакция на scroll — желаемое поведение v2, в legacy почти нет) |
| **Мобильный** | те же слои; `background-attachment: fixed` и циклы анимации бьют по батареи и FPS |
| **Удачно** | атмосфера, связь со стеклянными поверхностями, отличие от «белого корпоратива» |
| **Проблемы** | постоянное движение; нагрузка; слабый контроль `prefers-reduced-motion` на уровне слоёв |
| **Решение** | **адаптировать**: сатин / дымка / редкая золотая пыль; очень медленное собственное движение; лёгкая реакция на scroll; на мобильном — упрощение; при `prefers-reduced-motion` — статичный кадр. Точные оттенки не фиксировать до прототипа |

Рабочие направления фона (не утверждены): сатиновый серо-графитовый; приглушённый деловой персиковый; дымчато-фиолетовый; золотая пыль как редкий отблеск.

### 3.2. Бескаркасные поверхности

| | |
|--|--|
| **Селекторы** | `.hero-section`, `.benefit-card`, `.service-card`, `.specialist-content`, `.review-card`, панели квиза/чек-листа, `.hero-nav`, `.contact-accordion` |
| **Приём** | `rgba(255,255,255,0.15)` + `backdrop-filter: blur(20px)` + мягкая светлая обводка |
| **Удачно** | ощущение «парения» над фоном, не набор коробок |
| **Проблемы** | blur дорогой; контраст текста; если стекло на всём — монотонность |
| **Решение** | **адаптировать** выборочно; не превращать все секции в одинаковые белые карточки (запрет из принципов) |

### 3.3. Hover: подъём, тень, оттенок

| | |
|--|--|
| **Селекторы** | `.benefit-card:hover`, `.service-card:hover`, `.review-card:hover` (`translateY(-8px)`); CTA `translateY(-3px)`; `.contact-option:hover` |
| **Удачно** | единый язык «жива поверхность» |
| **Проблемы** | hover-центричность; `:focus-visible` слабее hover; на touch lift часто отключён |
| **Решение** | **сохранить** фирменные hover-реакции на интерактивных блоках; добавить явный focus; на мобильном — короткая реакция на tap без вечного «приподнятого» состояния |

### 3.4. Орбы отзывов («скитлс»)

| | |
|--|--|
| **Файлы** | `js/reviews-loader.min.js`; `css/main.min.css`; `data/reviews.json`; разметка `#reviews`, `#reviews-orbs-section`, `#reviews-grid-seo`, `#review-modal` |
| **Селекторы** | `.reviews-orbs-section`, `.review-orb-item.orb`, `.review-orb-initials`, `[data-orb-color=…]`, `@keyframes orbWaveOdd` / `orbWaveEven`; `.reviews-tooltip`; `.review-modal*`; мобильный `.review-accordion-item` (`<details>`) |
| **Ассеты** | `orb-base.svg`, `orb-gold.svg` на диске, **в рантайме почти не используются** (цвета через CSS + инициалы) |
| **Поведение** | idle — волна; hover/focus — пауза волны, scale, тултип (desktop >900px); click — модалка; mobile — аккордеон; mid-width — карточки с мини-орбами |
| **Удачно** | сильнейший фирменный интерактив; SEO-сетка в DOM; базовая a11y модалки (Escape, focus trap) |
| **Проблемы** | тройная ветка UI; постоянное движение; тултип не для touch; сложность поддержки |
| **Решение** | **сохранить механику орбов на главной**; успокоить motion; упростить ветки (desktop орбы + полный текст; mobile — список/аккордеон без потери смысла). **Запрещено** подменять слайдером карточек без отдельного согласования |

Канонический якорь блока в текущем `site`: `#reviews`.  
Пункт меню «Отзывы»: с главной → `/#reviews`, с внутренних → `/#reviews`.  
Русский алиас `#otzyvy` допустим только как дополнительный якорь с тем же блоком — не плодить два разных блока.

| | |
|--|--|
| **Файлы** | `index.html` (`.hero-nav`, `#main-nav`); `css/main.min.css`; `js/main.min.js` (`initScrollEffects` / mobile toggle) |
| **Селекторы** | `.hero-nav` (`position: fixed; left: 40px; top: ~200px; width: ~250px`); glass + blur; ссылки с Playfair; `a::before` золотой wipe; `a:hover` `translateX(8px)`; mobile `.hero-nav.active` fullscreen |

## 4. Категории решений (кратко)

### Сохранить

- характер живого фона (не плоский корпоратив);
- hover-подъём интерактивных поверхностей;
- орбы отзывов как фирменный жест главной;
- идею вертикальной desktop-навигации (до прототипа — не выкидывать);
- контактный объект-талисман (не generic FAB);
- фото Карины, логотип, Unbounded;
- принцип «небольшие неожиданные реакции интерфейса».

### Сохранить механику, изменить визуал

- фон (палитра, скорость, реакция на scroll);
- стекло / бескаркасность (выборочно);
- орбы (спокойнее, производительнее);
- вертикальное меню под многостраничник;
- анимации мандаринки / ромашки;
- микроанимации без вечных циклов.

### Сезонный компонент

- ромашка (обычный режим) / мандаринка (зима);
- снежная игра и предсказания;
- любые новогодние декоративные слои.

### Заменить

- разношёрстные иконки;
- Playfair как шрифт навигации;
- полный AOS-пакет;
- формулировки «проверьте бухгалтера» (этика — в карте главной).

### Не переносить

- копирование старой голубой палитры 1:1;
- вечный кипящий фон;
- постоянный снег вне сезона;
- мёртвые и тяжёлые SVG без роли;
- превращение уникальных механик «по мотивам» без разбора исходного кода.

## 5. Сезонная модель (предварительно)

| Параметр | Решение этапа |
|----------|----------------|
| Обычный режим | Контактный объект — **ромашка** (дизайн и ассет — позже) |
| Зимний режим | Ромашка → **мандаринка**; доступна игра со снежинками |
| Запуск снега | Только действием пользователя |
| Начало зимы | **20 декабря** (в конфигурации) |
| Конец зимы | После **14 января** (точную границу отключения уточним при реализации) |
| Ромашка | Рисует владелец; до готовности — **заглушка** |
| Страница всех отзывов | **Не нужна**; блок на главной + ссылки на оригиналы Яндекс Услуг/Карт |
| Вне сезона | Зимний JS/CSS/ассеты **не выполнять и по возможности не грузить** |
| Тестирование | Ручные режимы: `force-summer` / `force-winter` (имена рабочие) |
| Reduced motion | Без падения снега и без idle-bounce талисмана |

На этом этапе ромашку не рисовать и игру не переписывать — только зафиксировать архитектуру.

Наследуемое поведение мандаринки: фиксированный угол экрана → панель каналов связи → закрытие без потери контекста страницы.

Наследуемое поведение снега: тоггл / баннер согласия на mobile → кликабельные снежинки → модалка предсказания → лимит попыток → завершение без блокировки сайта.

## 6. Desktop / tablet / mobile

| Уровень | Требования наследия |
|---------|---------------------|
| **Desktop** | Живой (спокойный) фон; вертикальная навигация как кандидат №1; орбы отзывов; талисман контактов; hover-язык |
| **Tablet** | Не уменьшенный desktop; орбы допустимы в упрощённой раскладке или переход к списку раньше, чем на phone |
| **Mobile** | Упрощённый/статичный фон; отдельное меню (не копия вертикальной рейки); отзывы без поля летающих шаров; талисман без вечного bounce; снег только opt-in в сезоне |
| **`prefers-reduced-motion`** | Статичный фон; без волны орбов; без bounce талисмана; без снега; короткие или нулевые transition |

## 7. Риски при переносе

1. Cursor «улучшит» орбы в слайдер, мандаринку в круглую FAB, фон в плоский `#f5f5f5`.
2. Вертикальное меню скопируют с якорями одностраничника и сломают многостраничную IA.
3. Сезонный код попадёт в основной бандл и будет грузиться круглый год.
4. `backdrop-filter` + анимированный фон убьют слабые телефоны.
5. Потеря SEO-текстов отзывов, если оставить только canvas/орбы без текстового DOM.
6. Конфликт текущего `#reviews` и желания назвать якорь `#otzyvy`.

---

## 8. Запреты для Cursor (без отдельного согласования)

1. Не заменять орбы отзывов обычным слайдером карточек.
2. Не заменять мандаринку/ромашку стандартной круглой FAB.
3. Не удалять вертикальную навигацию без прототипа и сравнения.
4. Не превращать все секции в одинаковые белые карточки.
5. Не убирать фирменные hover-реакции под предлогом минимализма.
6. Не переносить старые грубые и разношёрстные иконки как новую систему.
7. Не переписывать уникальные механики «по мотивам», не разобрав legacy-код.
8. Не включать снег и зимний декор вне сезона.
9. Не использовать формулировки, которые бьют по «вашему бухгалтеру» (см. карту главной).
