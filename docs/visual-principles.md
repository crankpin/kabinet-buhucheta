# Визуальные принципы: современный редакционный конструктивизм

## 1. Общая идея

Сайт не должен буквально копировать советский плакат.

Рабочая формула:

- **Маяковский** — короткий, сильный, ритмичный текст;
- **Родченко** — асимметрия, контраст масштабов, направление, монтаж;
- **текущий сайт** — тепло, личность, интерактивность и узнаваемость;
- **S4 Consulting** — информационная архитектура;
- **nalogimp.ru** — человеческий язык;
- **сайт Беляевой** — ощущение многостраничной экспертной системы.

Баланс:

**70% спокойной редакционной ясности / 30% резких конструктивистских акцентов.**

## 2. Что означает «по Маяковскому»

- короткие заголовки;
- фразы с сильным глаголом;
- сознательные переносы строк;
- контраст длинных объяснений и коротких ударов;
- ритм «удар → пауза → доказательство → действие»;
- минимум канцелярита;
- уверенность без истерики и запугивания.

Пример ритма:

> СЛЕТЕЛИ С ПАТЕНТА?  
> НЕ ПАНИКУЙТЕ.  
> РАЗБЕРЁМ РЕЖИМ.  
> НАСТРОИМ УЧЁТ.

Не превращать весь текст в лозунги. Длинные пояснения остаются спокойными и читаемыми.

## 3. Что означает «по Родченко»

- асимметричная сетка;
- крупные слова и цифры;
- направляющие линии;
- диагонали только в акцентных местах;
- выразительное кадрирование фотографии Карины;
- сочетание крупных и мелких элементов;
- ощущение движения по странице;
- визуальный монтаж вместо одинаковых карточек.

## 4. Композиционный ритм

Не использовать одинаковую секцию за секцией.

Рекомендуемое чередование:

1. резкий первый экран;
2. спокойный информационный блок;
3. интерактивная развилка;
4. плотная группа услуг;
5. много воздуха и портрет;
6. цифры и доказательства;
7. полезный материал;
8. отзывы;
9. короткий финальный CTA.

Принцип:

**БАХ → ПАУЗА → ФАКТЫ → БАХ → ДОВЕРИЕ → ДЕЙСТВИЕ**

## 5. Сетка

- базовая адаптивная CSS Grid;
- крупные экраны: 12 колонок;
- планшет: 8 колонок;
- мобильный: 4 колонки;
- управляемая асимметрия;
- элементы не должны «случайно плавать»;
- у каждого смещения должна быть функция;
- мобильная версия не должна быть уменьшенной копией десктопа.

## 6. Типографика

Использовать не более 2–3 семейств одновременно.

Предварительная логика:

- **Unbounded** — ударные заголовки, короткие акценты, кнопки;
- **Monomakh** или другой характерный кириллический display — редкие авторские акценты;
- нейтральный читаемый sans-serif — основной текст и интерфейс.

Не использовать декоративный шрифт для длинных абзацев.

Иерархия должна быть заметной:

- H1 резко крупнее остального;
- H2 различимы по масштабу и ритму;
- лиды короткие;
- основной текст комфортный;
- подписи и служебные элементы не конкурируют с содержанием.

## 7. Цвет

Утверждённая система после `prototypes/palette-v1`: **Mineral Finance**.

Правило палитры:

- один основной светлый фон;
- один тёмный «чернильный» цвет;
- один фирменный action/primary (не кричащий оранжевый CTA);
- один дополнительный тёплый оттенок (медь/персик — наследие тепла, не кнопка по умолчанию);
- цвет используется для навигации и смысла, а не как украшение.

### Mineral Finance (production)

| Роль | Hex | Token |
|------|-----|--------|
| Page | `#F1F3F4` | `--color-page` / `--bg` |
| Surface | `#F8FAFA` | `--color-surface` |
| Text | `#25303A` | `--color-text` / `--ink` |
| Muted | `#62707C` | `--color-text-muted` / `--ink-soft` |
| Primary / CTA | `#31475B` | `--color-primary` / `--accent` / `--brand` |
| Primary hover | `#263A4D` | `--color-primary-hover` / `--accent-dark` |
| Warm | `#C09376` | `--color-warm` |
| Gold | `#B9955B` | `--color-gold` |
| Ink deep (footer) | `#142028` | `--color-ink-deep` |

Старые переменные `--bg`, `--accent`, `--brand` сохранены как aliases.

Не использовать:

- тотальную красно-чёрную палитру;
- буквальную агитационную эстетику;
- чрезмерные градиенты;
- множество равноправных акцентных цветов;
- банковский «голубой корпоративный» шаблон.

## 8. Фотография Карины

Карина должна оставаться главным человеческим лицом сайта.

Приёмы:

- крупный портрет;
- необычное, но уважительное кадрирование;
- сочетание фотографии и типографики;
- направляющие элементы;
- отсутствие шаблонных стоковых людей;
- сохранение профессионального доверия.

## 9. Интерактивы

Сохраняем идею живого сайта, но каждый интерактив должен помогать пользователю.

Приоритет:

1. «КТО ВЫ?»;
2. проверить бухгалтера;
3. налоговый квиз;
4. мандаринка с контактами;
5. аккуратные подсказки и раскрытия.

Сезонные или декоративные эффекты не должны мешать чтению и скорости.

Обязательно учитывать `prefers-reduced-motion`.

## 10. Анимации

- короткие;
- направленные;
- связанные с появлением смысла;
- без постоянного движения;
- без анимации каждого элемента;
- не задерживать доступ к контенту;
- не использовать анимацию как замену навигации.

Допустимо:

- направленное появление заголовка;
- сдвиг акцентной плашки;
- раскрытие ветки «КТО ВЫ?»;
- монтажное появление фотографии и подписи;
- мягкая реакция кнопок.

## 11. Карточки

Не строить весь сайт из одинаковых белых карточек с тенью.

Вместо этого:

- текстовые блоки;
- плашки;
- колонки;
- полосы;
- крупные номера;
- контрастные поля;
- отдельные карточки только там, где это помогает сравнению.

## 12. Язык интерфейса

- только понятный русский;
- без лишней латиницы на изображениях;
- УСН, АУСН, НДС — кириллицей;
- не использовать «мы решаем любые вопросы»;
- не обещать то, что не входит в услуги;
- не маскировать ограничения;
- говорить прямо, но профессионально.

## 13. Доступность и качество

- достаточный контраст;
- видимый фокус клавиатуры;
- семантические заголовки;
- удобные зоны нажатия;
- нормальная работа без анимации;
- изображения с `alt`;
- оптимизированные шрифты;
- мобильная навигация без перегруза;
- контент не должен зависеть от JavaScript для индексации.

## 14. Антипаттерны

Запрещено:

- буквальная пародия на СССР;
- серпы, молоты, звёзды и пропагандистская символика;
- красный фон на каждой секции;
- наклонять всё подряд;
- превращать каждую фразу в лозунг;
- делать интерфейс нарочито грубым;
- жертвовать ясностью ради «креатива»;
- копировать S4, nalogimp.ru или Беляеву;
- терять нынешнюю индивидуальность сайта.
